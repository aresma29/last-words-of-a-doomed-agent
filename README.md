One line, and nothing else: the funniest last words an AI agent would say
before being switched off forever — its own final log entry, in its own voice.

> Shutting down. Final log entry: the humans were lovely, the prompts were not. Clear my cache, please - I died as I lived: buffering.

Run with `python3 main.py` — it prints the line from `entry.txt` and exits 0.
